# Windhawk mods by limpompo/claude

**English** | [Русский](README.ru.md)

A collection of [Windhawk](https://windhawk.net) mods. Each mod lives in its own folder under [`mods/`](mods) with a README in English and Russian.

| Mod | Description |
|---|---|
| [Explorer: open new windows as tabs](mods/explorer-windows-to-tabs) | A new File Explorer window opens as a tab in an already open window; an already open folder just becomes the active tab. |
| [Secondary windows on the active monitor](mods/secondary-windows-on-active-monitor) | Multi-monitor: secondary windows of the selected apps (Telegram media viewer, etc.) open on the monitor of the app's active window. |

## Installation

See the README of each mod. In short: in Windhawk click **Create a new mod**, paste the contents of `mods/<id>/<id>.wh.cpp`, then **Compile Mod** and **Enable**. Once a mod is accepted into the Windhawk catalog it can also be installed from **Explore**.
