# Windhawk mods by limpompo

**English** | [Русский](README.ru.md)

A collection of [Windhawk](https://windhawk.net) mods. Each mod lives in its own folder under [`mods/`](mods) with a README in English and Russian.

| Mod | Description |
|---|---|
| [Explorer: open new windows as tabs](mods/explorer-windows-to-tabs) | A new File Explorer window opens as a tab in an already open window; an already open folder just becomes the active tab. |
| [Telegram: media viewer on the chat monitor](mods/telegram-viewer-monitor) | Telegram Desktop secondary windows (photo/video viewer, etc.) open on the monitor of the main window. |
| [Full labels in the context menu (RU)](mods/context-menu-full-labels-ru) | Replaces the abbreviated Russian items "Копир.", "Переим.", "Созд. ярлык" with full words. |

## Installation

Open Windhawk, go to **Explore**, search for the mod by name and click **Install** (once the mod is published in the Windhawk catalog).

Manual installation: in Windhawk click **Create a new mod**, replace the generated code with the contents of `mods/<id>/<id>.wh.cpp`, then **Compile Mod** and **Enable**.
