# Полные названия в контекстном меню (RU)

[English](README.md) | **Русский**

В некоторых сборках Windows 11 русский `shell32.dll.mui` содержит сокращённые пункты классического контекстного меню: **Копир.**, **Переим.**, **Созд. ярлык**. Этот мод для [Windhawk](https://windhawk.net) заменяет их на полные слова **Копировать**, **Переименовать**, **Создать ярлык**.

## Возможности

- Работает в Проводнике и в диалогах «Открыть / Сохранить / Выбор папки» любых программ.
- Перехватывает создание меню во всех процессах; системные файлы не изменяются.
- Отключили мод — всё возвращается к исходным названиям.

## Требования

- Windows 11 с русским языком интерфейса (на других языках мод бесполезен).
- [Windhawk](https://windhawk.net).

## Установка

1. Установите [Windhawk](https://windhawk.net).
2. В Windhawk нажмите **Create a new mod**, замените сгенерированный код содержимым файла [`context-menu-full-labels-ru.wh.cpp`](context-menu-full-labels-ru.wh.cpp), затем **Compile Mod** и **Enable**.

Мод отправляется в официальный каталог Windhawk. После принятия его можно будет установить напрямую: **Explore** -> поиск **Полные названия в контекстном меню (RU)** -> **Install**.
