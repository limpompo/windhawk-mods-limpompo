# Full labels in the context menu (RU)

**English** | [Русский](README.ru.md)

Some Windows 11 builds ship a Russian `shell32.dll.mui` with abbreviated items in the classic context menu: **Копир.**, **Переим.**, **Созд. ярлык**. This [Windhawk](https://windhawk.net) mod replaces them with the full words **Копировать**, **Переименовать**, **Создать ярлык**.

## Features

- Works in File Explorer and in the Open / Save / Select Folder dialogs of any program.
- Hooks menu creation in all processes; no system files are modified.
- Turn the mod off and everything returns to the original labels.

## Requirements

- Windows 11 with the Russian display language (the mod is useless on other languages).
- [Windhawk](https://windhawk.net).
## Installation

1. Install [Windhawk](https://windhawk.net).
2. Open Windhawk, go to **Explore** and search for **Full labels in the context menu (RU)** (once the mod is published in the Windhawk catalog).
3. Click **Install**.

Manual installation (before the mod appears in the catalog): in Windhawk click **Create a new mod**, replace the generated code with the contents of [`context-menu-full-labels-ru.wh.cpp`](context-menu-full-labels-ru.wh.cpp), then **Compile Mod** and **Enable**.
