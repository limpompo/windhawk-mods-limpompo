# Telegram: просмотрщик на мониторе чата

[English](README.md) | **Русский**

Telegram Desktop запоминает, на каком мониторе открывался просмотрщик медиа, и открывает его там же, даже если главное окно переехало на другой монитор. Этот мод для [Windhawk](https://windhawk.net) открывает второстепенные окна Telegram (просмотр фото/видео и др.) на том мониторе, где находится главное окно.

## Возможности

- Переносит второстепенное окно Telegram на монитор главного окна ещё до показа, поэтому оно не мелькает на старом мониторе.
- Окно сохраняет своё положение (окно в углу остаётся в том же углу другого монитора); окно больше целевого монитора уменьшается до его размера.
- Полноэкранное окно остаётся полноэкранным; развёрнутое остаётся развёрнутым и при восстановлении остаётся на новом мониторе.
- Учитываются мониторы с разным масштабом (например, 100% и 150%).
- Данные Telegram и системные файлы не изменяются.

## Настройки

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Сохранять положение окна | вкл | Вкл: окно сохраняет своё место (угол остаётся углом). Выкл: окно встаёт в центр монитора главного окна |
| Учитывать масштаб мониторов | вкл | Ставит окно так, чтобы оно поместилось после того, как Telegram изменит размер под другой масштаб (100% / 150%). Выключите, если на такой конфигурации окна встают неправильно |
| Развёрнутые окна — развёрнутыми | вкл | Вкл: развёрнутое окно открывается развёрнутым на новом мониторе и восстанавливается там же. Выкл: переносится как обычное (как в 1.0) |
| Фильтр по заголовку окна | пусто | Переносить только окна, в заголовке которых есть этот текст; пусто — все второстепенные окна |

## Какие окна переносятся

По умолчанию **все** второстепенные окна Telegram, а не только просмотрщик: также видео «картинка в картинке», окна звонков и чаты, открытые в отдельном окне. Если какие-то из них вы специально держите на другом мониторе, используйте настройку **Фильтр по заголовку окна**: тогда переносятся только окна, в заголовке которых есть заданный текст. Заголовки окон зависят от языка интерфейса Telegram, поэтому фильтр работает только для этого языка.

## Требования

- Telegram Desktop (`Telegram.exe`) в Windows.
- [Windhawk](https://windhawk.net).

## Установка

1. Установите [Windhawk](https://windhawk.net).
2. В Windhawk нажмите **Create a new mod**, замените сгенерированный код содержимым файла [`telegram-viewer-monitor.wh.cpp`](telegram-viewer-monitor.wh.cpp), затем **Compile Mod** и **Enable**.

Мод отправляется в официальный каталог Windhawk. После принятия его можно будет установить напрямую: **Explore** -> поиск **Telegram: просмотрщик на мониторе чата** -> **Install**.
