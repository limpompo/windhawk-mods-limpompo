# Проводник: новые окна — во вкладки

[English](README.md) | **Русский**

Когда открывается новое окно Проводника (Win+E, «Открыть в новом окне», «Показать в папке» из другой программы, папка с рабочего стола, ярлык и т. п.) и уже есть другое видимое окно Проводника, этот мод для [Windhawk](https://windhawk.net) прячет новое окно и:

- если папка уже открыта в какой-то вкладке — делает ту вкладку активной;
- иначе — добавляет новую вкладку в самое верхнее окно Проводника и открывает там папку.

## Возможности

- Выделенные файлы («Показать в папке») выделяются и во вкладке.
- Исправляет «Показать в папке» для уже открытой папки: Проводник выделяет файл, но не переключается на вкладку и не всегда выбирает нужную. Мод переключает на правильную вкладку.
- Новые вкладки открываются командой «Открыть в новой вкладке», как из контекстного меню.
- Зажмите **Shift** при открытии папки, чтобы получить отдельное окно.
- Панель управления никогда не сливается, и в её окно не добавляются вкладки других папок.
- Не сливаются: вкладка, вытащенная в отдельное окно, как бы быстро её ни вытащили (в момент появления нового окна вкладка уходит из другого окна), и окна на другом виртуальном рабочем столе. Папка, открытая двойным щелчком, сливается.
- Если что-то не вышло, новое окно показывается как обычно.
- Мод безопасно выключается: вся его работа идёт в одном потоке, который останавливается, и мод дожидается его завершения.

## Сравнение с Explorer Single Window Tabs

[Explorer Single Window Tabs](https://windhawk.net/mods/explorer-single-window-tabs) тоже открывает новые окна Проводника вкладками. Этот мод дополнительно переключается на вкладку, где папка уже открыта, переносит выделение «Показать в папке» в новую вкладку, исправляет «Показать в папке» для уже открытой папки, открывает вкладки командой «Открыть в новой вкладке» защищает вытащенные вкладки по зажатой кнопке мыши (помимо обхода по Shift, который есть в обоих модах) и показывает новое окно обратно, если вкладку открыть не удалось.

**Не включайте оба мода одновременно** — они оба будут обрабатывать каждое новое окно.

## Настройки

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Не открывать папку повторно | вкл | Переключиться на вкладку, если папка уже открыта |
| Переключаться на вкладку, где программа выделила файл | вкл | Исправляет переключение при «Показать в папке» |
| Выводить окно со вкладками на передний план | вкл | Активировать (и развернуть) окно Проводника |
| Shift — открыть отдельным окном | вкл | Если при открытии папки зажат Shift, окно остаётся отдельным |
| Не трогать вкладки, вытащенные в отдельное окно | вкл | Защита вытащенных вкладок; двойной щелчок по-прежнему сливается |

## Требования

- Windows 11 22H2 или новее (Проводник с вкладками); на более старых сборках мод не загружается.
- [Windhawk](https://windhawk.net).

## Известные ограничения

Команда окна «новая вкладка» (`WM_COMMAND 0xA21B`) и часть логики опираются на недокументированное поведение Проводника, поэтому будущая сборка Windows может сломать мод.

## Установка

1. Установите [Windhawk](https://windhawk.net).
2. В Windhawk нажмите **Create a new mod**, замените сгенерированный код содержимым файла [`explorer-windows-to-tabs.wh.cpp`](explorer-windows-to-tabs.wh.cpp), затем **Compile Mod** и **Enable**.

Мод отправляется в официальный каталог Windhawk. После принятия его можно будет установить напрямую: **Explore** -> поиск **Проводник: новые окна — во вкладки** -> **Install**.
