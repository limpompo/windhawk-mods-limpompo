# Проводник: новые окна — во вкладки

[English](README.md) | **Русский**

Когда открывается новое окно Проводника (Win+E, «Открыть в новом окне», «Показать в папке» из другой программы, папка с рабочего стола, ярлык и т. п.) и уже есть другое видимое окно Проводника, этот мод для [Windhawk](https://windhawk.net) прячет новое окно и:

- если папка уже открыта в какой-то вкладке — делает ту вкладку активной;
- иначе — добавляет новую вкладку в самое верхнее окно Проводника и открывает там папку.

## Возможности

- Выделенные файлы («Показать в папке») выделяются и во вкладке.
- Исправляет «Показать в папке» для уже открытой папки: Проводник выделяет файл, но не переключается на вкладку и не всегда выбирает нужную. Мод переключает на правильную вкладку.
- Новые вкладки открываются командой «Открыть в новой вкладке», как из контекстного меню.
- Не сливаются: окно, созданное при зажатой левой кнопке мыши (вкладка, вытащенная в отдельное окно), и окна на другом виртуальном рабочем столе.
- Если что-то не вышло, новое окно показывается как обычно.

## Настройки

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Не открывать папку повторно | вкл | Переключиться на вкладку, если папка уже открыта |
| Переключаться на вкладку, где программа выделила файл | вкл | Исправляет переключение при «Показать в папке» |
| Выводить окно со вкладками на передний план | вкл | Активировать (и развернуть) окно Проводника |
| Не трогать окна, созданные при зажатой кнопке мыши | вкл | Защита вытащенных вкладок |

## Требования

- Windows 11 22H2 или новее (Проводник с вкладками).
- [Windhawk](https://windhawk.net).

## Известные ограничения

Команда окна «новая вкладка» (`WM_COMMAND 0xA21B`) и часть логики опираются на недокументированное поведение Проводника, поэтому будущая сборка Windows может сломать мод.
## Установка

1. Установите [Windhawk](https://windhawk.net).
2. Откройте Windhawk, перейдите в **Explore** и найдите **Проводник: новые окна — во вкладки** (когда мод опубликован в каталоге Windhawk).
3. Нажмите **Install**.

Ручная установка (пока мода нет в каталоге): в Windhawk нажмите **Create a new mod**, замените сгенерированный код содержимым файла [`explorer-windows-to-tabs.wh.cpp`](explorer-windows-to-tabs.wh.cpp), затем **Compile Mod** и **Enable**.
