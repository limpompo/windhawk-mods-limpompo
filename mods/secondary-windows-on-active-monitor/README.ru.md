# Дочерние окна на активном мониторе

[English](README.md) | **Русский**

Пригодится, если у вас **несколько мониторов**. Многие приложения запоминают, на каком мониторе открывалось дочернее окно (просмотрщик, плеер, диалог), и открывают его там же, даже если вы уже работаете с приложением на другом мониторе. Например, Telegram Desktop открывает фото и видео на том мониторе, где просмотрщик был в прошлый раз, а не там, где чат. Этот мод для [Windhawk](https://windhawk.net) открывает дочерние окна выбранных приложений на том мониторе, где находится активное окно приложения.

![Пример: просмотрщик Telegram открывается на мониторе чата](https://github.com/user-attachments/assets/5000330f-0441-4c61-926e-526427c3e0c2)

## Возможности

- Работает с любым приложением: список приложений задаётся в настройках мода (по умолчанию — Telegram Desktop).
- Переносит дочернее окно на монитор активного окна ещё до показа, поэтому оно не мелькает на старом мониторе.
- Окно сохраняет своё положение (окно в углу остаётся в том же углу другого монитора); окно больше целевого монитора уменьшается до его размера.
- Полноэкранное окно остаётся полноэкранным; развёрнутое остаётся развёрнутым и при восстановлении остаётся на новом мониторе.
- Учитываются мониторы с разным масштабом (например, 100% и 150%).
- Данные приложений и системные файлы не изменяются.

## Настройки

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Приложения | `Telegram.exe` | Приложения, дочерние окна которых переносятся. Для каждого: **Процесс** — имя исполняемого файла (`Telegram.exe` или `Telegram`) или полный путь; **Фильтр по заголовку окна** — переносить только окна, в заголовке которых есть этот текст (пусто — все дочерние окна) |
| Сохранять положение окна | вкл | Вкл: окно сохраняет своё место (угол остаётся углом). Выкл: окно встаёт в центр монитора активного окна |
| Учитывать масштаб мониторов | вкл | Ставит окно так, чтобы оно поместилось после того, как приложение изменит размер под другой масштаб (100% / 150%). Выключите, если на такой конфигурации окна встают неправильно |

Изменения списка приложений применяются без перезапуска приложений.

## Какие окна переносятся

**Все** дочерние окна приложения, у которых есть своё окно и которые появляются, пока приложение активно: для Telegram также видео «картинка в картинке», окна звонков и чаты, открытые в отдельном окне. Меню, подсказки, уведомления и панели инструментов не переносятся. Если какие-то окна вы специально держите на другом мониторе, задайте для приложения **Фильтр по заголовку окна**. Заголовки окон часто зависят от языка интерфейса приложения, поэтому фильтр работает только для этого языка.

## Требования

- Windows с двумя и более мониторами.
- [Windhawk](https://windhawk.net).

## Установка

1. Установите [Windhawk](https://windhawk.net).
2. В Windhawk нажмите **Create a new mod**, замените сгенерированный код содержимым файла [`secondary-windows-on-active-monitor.wh.cpp`](secondary-windows-on-active-monitor.wh.cpp), затем **Compile Mod** и **Enable**.
3. В настройках мода добавьте нужные приложения в **Приложения**.

Мод отправляется в официальный каталог Windhawk. После принятия его можно будет установить напрямую: **Explore** -> поиск **Дочерние окна на активном мониторе** -> **Install**.
