# Моды Windhawk от limpompo

[English](README.md) | **Русский**

Коллекция модов для [Windhawk](https://windhawk.net). Каждый мод лежит в своей папке в [`mods/`](mods) с README на русском и английском.

| Мод | Описание |
|---|---|
| [Проводник: новые окна — во вкладки](mods/explorer-windows-to-tabs/README.ru.md) | Новое окно Проводника открывается вкладкой в уже открытом окне; уже открытая папка просто становится активной вкладкой. |
| [Telegram: просмотрщик на мониторе чата](mods/telegram-viewer-monitor/README.ru.md) | Окна Telegram Desktop (просмотр фото/видео и др.) открываются на мониторе главного окна. |

## Установка

См. README каждого мода. Кратко: в Windhawk нажмите **Create a new mod**, вставьте содержимое `mods/<id>/<id>.wh.cpp`, затем **Compile Mod** и **Enable**. Когда мод принят в каталог Windhawk, его можно ставить и из **Explore**.
